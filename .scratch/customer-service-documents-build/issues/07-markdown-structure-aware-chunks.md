# 07: รักษาโครงสร้าง Markdown ใน preview และการค้นคืน

**What to build:** แอดมินเพิ่มเอกสาร Markdown แล้วตรวจ preview และเผยแพร่ได้ โดยเนื้อหาที่บอตค้นพบยังรักษาหัวข้อ ย่อหน้า รายการสเปก และแถวตารางที่อ่านเป็นหน่วยเดียวกัน

**Blocked by:** [กำหนดกติกาแบ่ง Markdown โดยรักษาหน่วยความหมาย](../../customer-service-documents/issues/11-define-markdown-structure-aware-chunking.md).

**Status:** complete

- [x] Preview และ chunks ที่ publish สร้างจากกติกาเดียวกัน และแสดงลำดับกับหัวข้อที่เกี่ยวข้องอย่างถูกต้อง
- [x] รายการสเปกหรือแถวตารางที่มีขนาดไม่เกิน hard limit อยู่ครบใน chunk เดียว เช่น `น้ำหนักตัวเครื่อง: 620 กรัม`
- [x] หน่วยข้อความที่ยาวเกิน hard limit แบ่งด้วย fallback ที่ตัดสินใจไว้ โดยไม่มี token หายหรือมี chunk ที่เริ่มกลางค่าข้อมูล
- [x] ทดสอบเอกสารภาษาไทยที่มี heading, ย่อหน้า, bullet list, ตาราง Markdown และข้อความยาว พร้อมยืนยันว่า retrieval คืนข้อความที่อ่านรู้เรื่อง
