# แผนตัดสินใจสำหรับสเปก MVP บอต Customer Service

Labels: wayfinder:map
Status: open

## Destination

ได้สเปก MVP ที่พร้อมนำไปพัฒนา สำหรับบอตตอบคำถามลูกค้าแบบเปิดซอร์สบน GitHub ให้ผู้ใช้นำไปติดตั้งเอง โดยใช้ LLM และ RAG พร้อม feedback loop สำหรับแอดมิน
จบแผนเมื่อไม่มีประเด็นที่ต้องตัดสินใจก่อนเขียนสเปกและส่งต่อการพัฒนา

## Notes

- ใช้ `wayfinder`, `grilling`, `domain-modeling`; สนทนาเป็นภาษาไทย
- Tracker: [Local Markdown](../../docs/agents/issue-tracker.md); คำศัพท์: [CONTEXT.md](../../CONTEXT.md)
- ข้อกำหนดจากผู้ใช้ในช่วงกำหนดขอบเขต วันที่ 2026-09-22:
  - หนึ่งการติดตั้งรองรับหลายธุรกิจ ฐานความรู้ บอต และสถิติแยกกัน ลูกค้าเข้าหน้าเว็บของธุรกิจชัดเจน
  - เรียก LLM ภายนอกได้ ข้อมูลและส่วนประกอบอื่นติดตั้งและเก็บในเครื่องผู้ติดตั้ง ขอบเขตบริการภายนอกดูประเด็นที่ปิดใน Decisions so far
  - บอตตอบคำถามอย่างเดียว ผ่านหน้าเว็บเท่านั้น
  - แอดมินเพิ่ม แก้ไข ลบ Q&A ผ่านฟอร์ม และนำเข้าจากไฟล์ JSON
  - ถ้าข้อมูลไม่พอให้แจ้งและเก็บคำถาม ถ้ากำกวมให้ถามกลับ
  - แยกสัญญาณหัวข้อถามบ่อย คำถามที่ตอบไม่ได้ และ feedback ว่าคำตอบไม่ช่วยเหลือ
  - แอดมินตรวจและเผยแพร่ความรู้เอง ไม่เผยแพร่คำตอบที่ระบบสร้างโดยอัตโนมัติ
- แผนนี้เป็นการตัดสินใจ ยังไม่สร้างแอป ติดตั้งบริการ หรือเผยแพร่ GitHub
- ข้อเสนอใน child tickets ยังไม่ใช่ข้อกำหนดที่ตกลงแล้ว

## Decisions so far

- [สภาพแวดล้อมติดตั้งและขอบเขตบริการภายนอก](issues/01-installation-boundaries.md): CPU/Docker Compose, embeddings ในเครื่อง, OpenRouter, เปลี่ยนโมเดลผ่าน config และส่งเฉพาะบริบทจำเป็น
- [สิทธิ์แอดมินและขอบเขตการเข้าถึงแต่ละธุรกิจ](issues/02-admin-access.md): admin ล็อกอินและดูแลทุกธุรกิจ; user แชตและให้ feedback ได้โดยไม่ต้องล็อกอิน
- [รูปแบบ JSON และวงจรเผยแพร่ Q&A](issues/03-knowledge-lifecycle.md): นำเข้า array ของ question/answer เป็น draft แยกธุรกิจ ตรวจซ้ำก่อนเพิ่ม และเผยแพร่เมื่อสร้างดัชนีสำเร็จ

## Not yet specified

- รายละเอียดประสบการณ์แอดมินและสถานะหน้าจอ จะชัดขึ้นหลังตกลงวงจรเผยแพร่ความรู้และการจัดการ feedback
- ขอบเขตการทดสอบการแยกข้อมูลและคุณภาพคำตอบ ต้องแตกเป็นกรณีทดสอบตามรูปแบบสิทธิ์และเกณฑ์คุณภาพที่ตกลง

## Out of scope

- การเขียนและ deploy แอปในแผนนี้: ปลายทางคือสเปก MVP
- บอตทำธุรกรรม ตรวจออเดอร์ หรือดำเนินงานแทนลูกค้า: ผู้ใช้กำหนดให้ตอบคำถามอย่างเดียว
- ช่องทาง LINE และช่องทางอื่น: MVP ใช้เว็บเท่านั้น
- การนำ feedback ไปเผยแพร่เป็นความรู้อัตโนมัติ: ต้องผ่านแอดมิน
