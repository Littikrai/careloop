# สภาพแวดล้อมติดตั้งและขอบเขตบริการภายนอก

## Question

เครื่องและระบบปฏิบัติการเป้าหมายคืออะไร ผู้ติดตั้งยอมรับขั้นตอนตั้งค่าแบบใด มีผู้ให้บริการ LLM ที่ต้องรองรับหรือไม่ และ embeddings ต้องทำในเครื่องหรือส่งออกได้? ต้องระบุข้อมูลที่ส่งภายนอก ปริมาณธุรกิจ/Q&A/บทสนทนา ภาษา งบ API และเป้าหมายเวลาตอบ เพื่อใช้ตัดสินสถาปัตยกรรมภายหลัง

## Comments

### ข้อตกลงบางส่วนจากผู้ใช้ — 2026-09-22

- Embeddings ใช้ `sentence-transformers` โดยยังไม่ได้เลือกโมเดล
- LLM API ใช้ OpenRouter โดยยังไม่ได้เลือกโมเดล
- จากขอบเขตที่ผู้ใช้ตกลงก่อนหน้า ส่วน embeddings จะรันในเครื่องผู้ติดตั้ง การตั้งค่าครั้งแรกและการดาวน์โหลดโมเดลยังต้องระบุ
- ยังไม่ปิดประเด็นนี้: ต้องตกลงขอบเขตข้อมูลที่ส่งให้ LLM และนโยบายการเลือกโมเดล

### ข้อกำหนดเพิ่มเติมจากผู้ใช้

- CPU เป็นเป้าหมายหลัก ไม่บังคับ GPU
- ตั้งเป้าให้ติดตั้งได้บน Windows, macOS และ Linux ผ่าน Docker Compose พร้อมไฟล์ตั้งค่า API key การรองรับฝั่งติดตั้งต้องตรวจสอบแยกจากการใช้งานเว็บผ่านเบราว์เซอร์
- ไม่ล็อกภาษาของเนื้อหา Q&A และบทสนทนา ไม่ตีความว่าโมเดลใดโมเดลหนึ่งรองรับทุกภาษาได้ดีเท่ากัน ภาษาของ UI ยังไม่ได้ตัดสินใจ
- ไม่กำหนดจำนวนธุรกิจ จำนวน Q&A หรือจำนวนผู้ใช้พร้อมกันเป็นข้อจำกัดผลิตภัณฑ์จากการประมาณการ ผู้ติดตั้งประเมินทรัพยากรและค่าใช้จ่ายตามงานของตนเอง
- ไม่อ้างว่ารองรับปริมาณงานไม่จำกัด และไม่ตั้งตัวเลขรับประกันความเร็วหรือความจุที่ยังไม่ได้ทดสอบ
- ไม่ขอประมาณการปริมาณใช้งานจากเจ้าของโครงการซ้ำเพื่อเป็นเงื่อนไขก่อนเดินหน้าวางสเปก

### Resolution — ข้อตกลงสุดท้าย

- ติดตั้งเองผ่าน Docker Compose พร้อม config โดยตั้งเป้า CPU และ Windows/macOS/Linux; ต้องตรวจสอบการติดตั้งจริงก่อนอ้างว่ารองรับครบ
- ใช้ sentence-transformers ในเครื่อง และ OpenRouter สำหรับเรียก LLM ภายนอก
- มีโมเดลเริ่มต้นพร้อมใช้ เปลี่ยนโมเดล embeddings และ LLM ได้ผ่าน config file โดยไม่ต้องแก้โค้ด หากเปลี่ยน embeddings ต้องสร้างดัชนีใหม่ให้ตรงกับโมเดล
- ส่งเฉพาะคำถาม ประวัติสนทนาที่จำเป็น และ Q&A ที่เกี่ยวข้องกับคำตอบไปยัง OpenRouter เพื่อลดข้อมูลที่ส่งและการใช้โทเคน ฐานความรู้ทั้งหมดและสถิติเก็บในเครื่อง
- ไม่จำกัดภาษาของ Q&A/บทสนทนา คุณภาพขึ้นกับโมเดลที่ผู้ติดตั้งเลือก
- ผู้ติดตั้งประเมินทรัพยากรและค่าใช้จ่ายเอง ไม่ต้องขอประมาณการขนาดงานก่อนทำสเปก และไม่มีการรับประกันความจุ/เวลาตอบโดยไม่มีผลทดสอบ
- ชื่อโมเดลเริ่มต้น รายละเอียด config และส่วนประกอบระบบที่ยังไม่เลือก ส่งต่อไปยัง [ชุดเทคโนโลยีและค่าเริ่มต้นพร้อมติดตั้ง](08-runtime-defaults.md) เพื่อไม่ให้ประเด็นตกหล่น
