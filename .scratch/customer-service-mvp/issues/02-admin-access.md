# สิทธิ์แอดมินและขอบเขตการเข้าถึงแต่ละธุรกิจ

## Question

MVP มีเจ้าของระบบคนเดียวดูแลทุกธุรกิจ หรือมีแอดมินหลายบัญชีที่จำกัดสิทธิ์รายธุรกิจ? ลูกค้าเข้าเว็บโดยไม่ล็อกอินได้หรือไม่ และต้องป้องกันการใช้บอตสาธารณะเกินขอบเขตอย่างไร?

## Comments

### ข้อตกลงบางส่วนจากผู้ใช้

- มีเพียงสองบทบาท: admin และ user ไม่ออกแบบระบบสิทธิ์ย่อยซับซ้อน
- admin หมายถึงแอดมินผู้ดูแล ส่วน user หมายถึงลูกค้าที่ใช้เว็บแชต
- ข้อเสนอขอบเขต MVP: admin ดูแลทุกธุรกิจในการติดตั้งนั้นได้ และ user คุยกับบอต/ให้ feedback โดยข้อมูลคำตอบแยกตามธุรกิจ ไม่มีการกำหนดสิทธิ์แอดมินรายธุรกิจ
- ยังต้องตกลงว่า user ใช้เว็บแชตได้ทันทีหรือต้องล็อกอิน ข้อเสนอคือไม่ต้องล็อกอินสำหรับ user และล็อกอินเฉพาะ admin

### Resolution — ผู้ใช้ยืนยันตามข้อเสนอ

- มีเพียง admin และ user
- admin ต้องล็อกอินก่อนเข้าหน้าจัดการ และดูแลทุกธุรกิจในการติดตั้งนั้นได้ ไม่กำหนดสิทธิ์ย่อยรายธุรกิจ
- user เปิดหน้าเว็บแชตของธุรกิจแล้วคุยและให้ feedback ได้ทันที โดยไม่ต้องสมัครบัญชีหรือล็อกอิน
- สิทธิ์ admin ครอบคลุมการจัดการธุรกิจ Q&A และการดูสถิติ/feedback
- การไม่ล็อกอินไม่ได้ยกเลิกการแยกข้อมูลธุรกิจ และไม่ให้สิทธิ์เข้าถึงหน้าจัดการหรือบทสนทนาของลูกค้ารายอื่น
- การจำกัดการเรียกใช้งานหน้าแชตสาธารณะเป็นรายละเอียดการตั้งค่าที่ยังไม่ตัดสินใจ ส่งต่อไปยัง [ชุดเทคโนโลยีและค่าเริ่มต้นพร้อมติดตั้ง](08-runtime-defaults.md)
