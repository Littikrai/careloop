# งานพัฒนา Customer Service MVP

ผู้ใช้อนุมัติการแบ่งงาน 8 tickets และ dependency ตามร่างในบทสนทนาแล้ว

Tracker เป็น Local Markdown; นี่คืองานพัฒนาแยกจาก decision tickets ของ wayfinder และไม่ใช่การยืนยันว่าประเด็นตัดสินใจเดิมปิดครบแล้ว

`ready-for-agent` หมายถึงจัดรูปแบบงานพร้อมให้หยิบตาม dependency; หากมีหัวข้อรายละเอียดที่ต้องสรุป ให้ตัดสินใจส่วนเหล่านั้นก่อนลงมือพัฒนาส่วนที่ขึ้นต่อกัน ไม่ตีความการอนุมัติการแบ่งงานเป็นการอนุมัติคำตอบที่ยังไม่ได้เลือก
