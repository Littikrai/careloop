# 07: เปลี่ยนโมเดลผ่าน config

**What to build:** ผู้ติดตั้งเปลี่ยนโมเดล OpenRouter หรือ sentence-transformers ผ่าน config ได้ และสร้างดัชนีความรู้ใหม่โดยไม่สูญเสีย Q&A ต้นฉบับ

**Blocked by:** 02: เพิ่ม Q&A แล้วถามบอตได้จริง.

**Status:** ready-for-agent

- [ ] มีค่าเริ่มต้นและเอกสารสำหรับเปลี่ยนโมเดลทั้งสองชนิดโดยไม่แก้โค้ด ระบุชัดว่าต้อง restart หรือเรียกขั้นตอนใดเพื่อให้มีผล
- [ ] เปลี่ยนโมเดล OpenRouter แล้วคำถามใหม่ใช้ค่าที่ตั้งไว้ พร้อมข้อผิดพลาดที่เข้าใจได้เมื่อโมเดลหรือ credentials ใช้ไม่ได้
- [ ] เปลี่ยน embeddings แล้วตรวจพบว่าดัชนีเดิมใช้ร่วมไม่ได้ และมีขั้นตอน reindex ความรู้ที่เผยแพร่จากต้นฉบับ
- [ ] การค้นใช้โมเดลกับดัชนีที่ตรงกันเสมอ ไม่ผสม vectors ต่างโมเดลแม้จำนวนมิติเท่ากัน; ระหว่าง reindex แสดงสถานะตามจริง
- [ ] reindex ล้มเหลวไม่ทำลายต้นฉบับและลองใหม่ได้; หลังสำเร็จค้นแยกธุรกิจและไม่คืนรายการ draft/ลบ/รุ่นเก่า
- [ ] ตรวจเปลี่ยน LLM และเปลี่ยน embeddings รวมถึง failure/retry พร้อมระบุว่าคุณภาพภาษาขึ้นกับโมเดลที่เลือก

## รายละเอียดที่ต้องสรุปก่อนดำเนินงานส่วนที่เกี่ยวข้อง

กำหนดวิธีสลับดัชนีและพฤติกรรมระหว่าง reindex ให้ชัดก่อนพัฒนา โดยรักษาเงื่อนไขไม่ค้นด้วยโมเดลกับดัชนีคนละรุ่น
