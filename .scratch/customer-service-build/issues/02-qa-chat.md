# 02: เพิ่ม Q&A แล้วถามบอตได้จริง

**What to build:** แอดมินกรอก Q&A ตรวจและเผยแพร่ ลูกค้าเปิดเว็บของธุรกิจแล้วถาม ระบบค้นความรู้ด้วย embeddings ในเครื่องและใช้ OpenRouter สร้างคำตอบ

**Blocked by:** 01: ติดตั้งระบบและจัดการธุรกิจ.

**Status:** ready-for-agent

- [ ] กรอก question/answer ที่ไม่ว่างเพื่อสร้าง draft ได้ และเผยแพร่เป็นรายรายการหรือหลายรายการได้
- [ ] ใช้ sentence-transformers บน CPU สร้าง embeddings จากคำถาม และเก็บคำตอบกับขอบเขตธุรกิจ; ไม่ต้องกรอก vectors เอง
- [ ] ใช้เฉพาะความรู้ที่เผยแพร่และสร้างดัชนีสำเร็จของธุรกิจปัจจุบัน พร้อมตรวจการแยกธุรกิจที่ชั้นระบบ ไม่อาศัยคำสั่งให้ LLM แยกข้อมูลเพียงอย่างเดียว
- [ ] เว็บแชตส่งคำถามและแสดงคำตอบผ่าน OpenRouter ได้จริง โดยส่งเฉพาะคำถาม บริบทสนทนาจำเป็น และ Q&A ที่เกี่ยวข้อง; API key อยู่ฝั่งระบบ
- [ ] เมื่อข้อมูลไม่พอให้แจ้ง; เมื่อกำกวมให้ถามกลับ; เมื่อ embeddings หรือ LLM ล้มเหลวให้แสดงสถานะตรงตามจริงและไม่เผยแพร่ความรู้ที่ยังสร้างดัชนีไม่สำเร็จ
- [ ] เก็บ Q&A ต้นฉบับในเครื่องเพื่อสร้างดัชนีใหม่ภายหลัง และมีโมเดลเริ่มต้นที่ระบุชื่อชัดเจน
- [ ] ตรวจเส้นทางเผยแพร่ → ค้น → ตอบ และกรณีไม่มีคำตอบ/บริการล้มเหลว/ธุรกิจสองแห่งมีคำถามเหมือนกันแต่คำตอบต่างกัน; draft ต้องไม่ถูกใช้ตอบ

## รายละเอียดที่ต้องสรุปก่อนดำเนินงานส่วนที่เกี่ยวข้อง

ก่อนลงรายละเอียด ต้องสรุปประเด็นขอบเขตคำตอบ: การใช้ความรู้ทั่วไป แหล่งอ้างอิง ประวัติสนทนา ข้อมูลขัดแย้ง และเกณฑ์ข้อมูลเพียงพอ พร้อมเลือกโมเดลเริ่มต้นและวิธีจำกัดการเรียกเว็บสาธารณะ ค่าเหล่านี้ยังไม่ได้รับการยืนยัน
