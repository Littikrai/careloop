# 05: เก็บบทสนทนาและ feedback

**What to build:** ลูกค้าให้ feedback ต่อคำตอบได้ แอดมินเปิดดูบทสนทนา คำถามที่ตอบไม่ได้ และ feedback แยกธุรกิจ พร้อมลบข้อมูลตามนโยบายที่ตกลง

**Blocked by:** 02: เพิ่ม Q&A แล้วถามบอตได้จริง.

**Status:** ready-for-agent

- [ ] บันทึกคำถาม คำตอบ เวลา ธุรกิจ และสถานะการตอบที่ตกลงไว้ โดยผูกข้อความกับบทสนทนาที่ถูกต้อง
- [ ] ลูกค้าให้ feedback ต่อคำตอบของบทสนทนาตนเองได้ โดยไม่ต้องมีบัญชี; ไม่สามารถอ่านหรือแก้ feedback ของบทสนทนาผู้อื่นผ่านการเดารหัส
- [ ] admin เปิดดูรายการและรายละเอียดบทสนทนา พร้อมกรองคำถามที่ตอบไม่ได้และ feedback เชิงลบได้
- [ ] แยกข้อผิดพลาดบริการออกจากคำถามที่ขาดความรู้ เพื่อไม่ทำให้รายงานช่องว่างความรู้ผิดความหมาย
- [ ] ลบบทสนทนาและข้อมูลเกี่ยวข้องได้ตามนโยบายที่บันทึกไว้ และบังคับใช้ระยะเวลาเก็บตามข้อสรุป
- [ ] ตรวจเส้นทางแชต → ให้ feedback → admin เห็นข้อมูล → ลบ รวมทั้งการแยกธุรกิจและบทสนทนา

## รายละเอียดที่ต้องสรุปก่อนดำเนินงานส่วนที่เกี่ยวข้อง

ก่อนออกแบบข้อมูล ให้สรุปข้อมูลที่เก็บ ตัวระบุบทสนทนา ค่า feedback และวิธีเปลี่ยนคะแนน ระยะเวลาเก็บ และผลของการลบต่อสถิติจากประเด็นข้อมูลสนทนาที่เก็บและระยะเวลาเก็บรักษา ไม่สมมติระยะเวลาขึ้นเอง
