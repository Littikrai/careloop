# 04: นำเข้า Q&A จาก JSON

**What to build:** แอดมินเลือกธุรกิจ อัปโหลดไฟล์ JSON ตรวจรายการ และเผยแพร่เป็นความรู้ที่บอตตอบได้ พร้อมเห็นผลรายรายการ

**Blocked by:** 02: เพิ่ม Q&A แล้วถามบอตได้จริง.

**Status:** ready-for-agent

- [ ] รับ UTF-8 JSON array ที่แต่ละรายการมี question และ answer เป็น string ไม่ว่างเท่านั้น โดยระบบสร้างรหัสและกำหนดธุรกิจให้
- [ ] ตรวจทั้งไฟล์ก่อนสร้าง draft; JSON ผิดรูปแบบ array ว่าง ฟิลด์ผิด/เกิน หรือคำถามเดิมคำตอบต่าง ให้ปฏิเสธพร้อมตำแหน่งและเหตุผล โดยไม่เขียนบางส่วน
- [ ] เปรียบเทียบหลัง trim และ Unicode NFC; คู่คำถาม/คำตอบซ้ำภายในไฟล์หรือกับรายการที่ยังไม่ถูกลบของธุรกิจเดียวกันให้ข้าม และไม่เพิ่มซ้ำเมื่ออัปโหลดเดิม
- [ ] การนำเข้าเพิ่มรายการเท่านั้น ไม่ลบรายการนอกไฟล์ ไม่แทนที่ collection และไม่เขียนทับคำตอบที่ขัดแย้ง
- [ ] แอดมินตรวจ draft แล้วเผยแพร่ได้; รายงานสำเร็จ ข้ามซ้ำ และล้มเหลวตามจริง โดยรายการสร้างดัชนีล้มเหลวไม่ถูกใช้ตอบ
- [ ] ตรวจตั้งแต่อัปโหลดจนถามคำถามที่นำเข้าได้ รวมถึงไฟล์ผิดรูปแบบ นำเข้าซ้ำ และการแยกข้อมูลธุรกิจ
