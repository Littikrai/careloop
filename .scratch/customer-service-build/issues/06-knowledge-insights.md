# 06: เห็นคำถามยอดนิยมและเติมช่องว่างความรู้

**What to build:** แอดมินเห็นคำถามที่ลูกค้าสนใจในแต่ละช่วงเวลา แยกจากคำถามที่ตอบไม่ได้และ feedback เชิงลบ แล้วนำคำถามไปสร้าง Q&A ฉบับร่างและเผยแพร่เอง

**Blocked by:** 05: เก็บบทสนทนาและ feedback.

**Status:** ready-for-agent

- [ ] แสดงกลุ่มคำถามซ้ำและจำนวนตามช่วงเวลา แยกธุรกิจ โดยมีนิยามการนับและการจัดกลุ่มที่บันทึกชัดเจน
- [ ] แสดงคำถามยอดนิยม คำถามที่ตอบไม่ได้ และ feedback เชิงลบเป็นคนละสัญญาณ แม้คำถามเดียวกันอาจอยู่ได้หลายกลุ่ม
- [ ] admin เปิดดูตัวอย่างคำถามและบทสนทนาต้นทางของกลุ่มได้ภายใต้ข้อมูลที่ยังไม่ถูกลบ
- [ ] admin นำคำถามที่พบไปสร้าง draft Q&A เพิ่มคำตอบ ตรวจและเผยแพร่ผ่านเส้นทางเดิมได้ โดยไม่เผยแพร่ความรู้จาก feedback อัตโนมัติ
- [ ] การแสดงว่าได้เพิ่มความรู้แล้วไม่เท่ากับอ้างว่าปัญหาคำตอบหายแล้ว และมีความเชื่อมโยงกับรายการความรู้ที่สร้าง
- [ ] ตรวจเส้นทางคำถามซ้ำ/ตอบไม่ได้ → dashboard → สร้างความรู้ → ถามใหม่ รวมถึงช่วงเวลาและผลการลบข้อมูลต้นทาง

## รายละเอียดที่ต้องสรุปก่อนดำเนินงานส่วนที่เกี่ยวข้อง

ก่อนเริ่ม ให้สรุปว่าจะจัดกลุ่มจากข้อความหรือความหมาย หน่วยการนับ ช่วงเวลารายงาน และสถานะติดตามจากประเด็นการจัดกลุ่มคำถามซ้ำและการติดตามช่องว่างความรู้ โดยไม่ถือว่าวิธี clustering ถูกเลือกแล้ว
